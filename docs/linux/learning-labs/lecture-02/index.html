    Explore the mechanics
    Permission calculator
    For directories, x means traversal; removing a file depends on its parent directory's w+x permissions.
    Ordinary files begin at 666; directories begin at 777. Umask removes bits; it does not add execute permission.
    Network diagnosis ladder
    Cron expression explorer
    Cron runs with a limited environment. Use absolute paths, capture errors, and check the scheduler's timezone. Timers can recover missed runs with Persistent=true.
    Recovery planning
    A successful archive command is only the start. Verify checksums, restore into a separate directory, compare the data, and measure recovery time. Keep independent off-host copies.
